# Performance Learning Log

Use this file to remember what actually worked or failed after posts are published. Do not treat it as a place for opinions only; record observable outcomes whenever possible.

## Entry Format

```markdown
## YYYY-MM-DD - Post Title

- Topic:
- Source/benchmark:
- Story shape:
- Visual format:
- Card count:
- Cover hook:
- Caption first line:
- Posted time:
- Reach/views:
- Likes:
- Comments:
- Saves:
- Shares:
- Profile visits/follows:
- Strongest signal:
- Weakest signal:
- Comment patterns:
- What to repeat:
- What to avoid:
- Next variation idea:
```

## Notes

- If performance is weak, diagnose topic and hook before blaming design.
- If comments are weak, check whether the post actually gave viewers an easy reason to answer.
- If saves are weak, check whether the post contains practical, surprising, or reference-worthy information.
- If shares are weak, check whether the post gives viewers a reason to send it to a friend.
- If the image is beautiful but reach is weak, the hook or topic may still have failed the click competition test.
